OutbreakWatch

← Back to dashboard

Outbreak Watch aggregates infectious-disease and mortality surveillance data from six official public health sources into one cross-linked, searchable dashboard. This page documents how it's built, how often it updates, and — source by source — exactly what each number does and doesn't mean.

What this is

A static site with no backend: a GitHub Actions workflow fetches all six sources every 6 hours, writes the results as plain JSON files, and GitHub Pages serves them directly. There is no database, no server-side code, and no manual curation of the data itself — everything shown is pulled straight from each source's own API or published file, then reshaped for display.

The source code is public, including every fetch script, so any figure on this site can be traced back to exactly how it was computed.

Data sources

World (WHO)

WHO Disease Outbreak News · global · event-driven, not scheduled

Groups individual WHO Disease Outbreak News (DON) reports into outbreaks, using WHO's own event grouping where present. Case and death counts, and country associations, are extracted automatically from each report's free text.

Extraction is regex/keyword-based, not a WHO-provided structured field — figures may be incomplete or lag the source text. Always verify against the linked DON before using clinically or in publication.

United States (CDC)

CDC NNDSS · weekly, all 50 states + territories

State-level counts are the latest provisional week from the National Notifiable Diseases Surveillance System, fetched from CDC's open data platform.

The most recent week is provisional and will revise upward as late reports arrive. A blank state for a given disease means it isn't nationally notifiable there, or data was unavailable that week — not that it had zero cases.

Brazil (InfoGripe)

Fiocruz (PROCC) / FGV (EMAp) / Ministry of Health · weekly, all 27 states

Covers Severe Acute Respiratory Syndrome (SRAG) only — the condition InfoGripe tracks — not a general outbreak feed. InfoGripe's own short/long-term trend classification (labeled "InfoGripe" in the state detail view) is shown alongside Outbreak Watch's independently computed one, so the two can be compared directly.

The most recent epidemiological week is provisional and will revise as more reports arrive. Risk levels ("intensidade") are Fiocruz's own population-adjusted classification, not raw case counts.

Chile (DEIS/MINSAL)

Chile Ministry of Health · weekly, all 16 regions

This mode shows all-cause mortality, not a specific disease — it was the only Latin American national dataset found (beyond Brazil) that was both structured and genuinely current. Chile's actual notifiable-disease surveillance (ENO) is roughly a year stale due to anonymization review.

The most recent week's death count is almost always an undercount — deaths take time to register — so the "vs. baseline" percentage and trend classification for the latest week are not reliable signals; treat them as provisional.

England (UKHSA)

UKHSA data dashboard API · weekly, 9 English regions

England only — Scotland, Wales, and Northern Ireland run their own public health agencies not covered here. Each disease uses whichever of UKHSA's published indicators for it currently has the most recent data (test positivity, case counts, syndromic rates).

The unit varies disease to disease and is always shown alongside the figure — never compare raw numbers across two diseases without checking the unit first. A disease with no indicator updated in the last 90 days is left out entirely rather than shown with stale numbers.

Japan (JIHS/IDWR)

Japan Institute for Health Security (formerly NIID) · weekly, all 47 prefectures

Two kinds of diseases are mixed together here: "sentinel" diseases (common illnesses like flu, RSV, hand-foot-mouth disease) are counts from a fixed network of reporting clinics, not a national total; "all-case" diseases (measles, TB, syphilis, dengue, and other nationally notifiable conditions) are comprehensive counts.

Sentinel-site counts are useful for tracking trend direction, not absolute national burden — real case counts are higher. Figures are provisional and may be revised in JIHS's later confirmed annual reports.

Cross-source linking

A WHO outbreak's detail view links to matching local data in the other five sources when the outbreak's country and disease overlap with what that source tracks; local-mode detail views link back to WHO the same way.

Matching is a best-effort keyword overlap on free-text disease names — there is no shared disease taxonomy across six independent sources published in five languages — so it's deliberately conservative: a missed link is preferred over a wrong one.

Growth rate & trend classification

Every entity (a WHO outbreak, a CDC disease's national total, a Brazilian/Chilean/ English region, a Japanese disease) gets two related but distinct numbers:

  • Percent change — the literal difference between the latest and previous reporting period.
  • Trend (rising / falling / stable) — fit by linear regression over the trailing few periods rather than a two-point comparison, so a single noisy week doesn't flip the label.

These two numbers are deliberately shown with different framing ("vs previous report" vs. "recent trajectory") because they can legitimately disagree: a big prior spike can leave a series classified "rising" even the week immediately after a real decline, because it's still elevated relative to the rest of the trailing window. That's correct behavior, not a bug — but it would look contradictory if the two numbers weren't labeled as describing different timeframes.

This is a descriptive read of each series, not an epidemiological model. There is no effective reproduction number (Rt), no serial interval, and no forecast — computing a defensible Rt requires a disease-specific serial interval, which isn't something this project sources or claims to have.

Implementation: scripts/lib/trend.mjs.

Update cadence & reliability

All six sources are re-fetched every 6 hours by a GitHub Actions workflow. Each source's fetch step runs independently — if one source's upstream API is down or changes shape, the other five still update and deploy normally, and a data/status.json health file records which sources last succeeded or failed. The dashboard shows a warning badge when a source hasn't updated successfully.

Follow updates

New and updated WHO Disease Outbreak News reports are available as an RSS feed — subscribe in any feed reader to get them without revisiting the site. The other five sources are recurring weekly counts rather than dated articles, so they aren't included in the feed to avoid republishing the same number every cycle.

Limitations & scope

This is a hobbyist/educational aggregation project, not a public health authority. It reformats and cross-links data that is already public, but every figure should be verified against its original source — linked throughout the dashboard — before being used clinically, in reporting, or in research. See the README for the full, ongoing list of what's been tried, built, and explicitly ruled out (additional countries, additional metrics, and why).
